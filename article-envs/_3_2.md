# `.dll`ファイルのビルド

C#では、`.dll`ファイルを出力する操作を**ビルド**と言います。

ビルドをするためのコマンドは以下の一文です。

```sh
dotnet build
```

`Ctrl + Shift + @`でターミナルを開き、打ち込んで実行してください。  
一瞬の待機の後に成功を示すログが表示されれば問題ありません。

![Output](~/images/envs_3_1.png)

作成したフォルダの`/bin/Debug/net48`に指定したファイル名の`.dll`が存在するはずです。  
一緒に出力される`.pdb`ファイルを気にする必要はありません。

こうして作成した`.dll`ファイルをMODの`Assemblies`フォルダに入れると読み込まれて動作します。
